# Chat Site

这是一个静态聊天页面项目，包含联系人管理、头像上传和模拟消息回复功能。

## 运行

1. 在 VS Code 中打开本项目文件夹。
2. 使用命令面板运行任务：`Tasks: Run Task` -> `Open Chat Site in Browser`。
3. 或直接在浏览器中打开 `index.html`。

## 已完成

- 页面结构完整，包含联系人管理、聊天消息区、输入区、功能面板和头像上传弹层。
- 本地存储支持多联系人、头像保存和旧数据兼容。
- 已生成 `.vscode/tasks.json`，可通过 VS Code 任务快速打开页面。
